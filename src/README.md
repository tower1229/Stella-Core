# Runtime Source Layout

Planned Stella Cortex modules:

```text
src/
├── routing/    turn lane classification
├── situation/  Situation Frame construction
├── twin/       context, hypotheses, prediction
├── framework/  compiler, registry, selector
├── reality/    world/social intelligence orchestration
├── praxis/     packet, episodes, outcomes, playbook
├── learning/   prediction error and consolidation
├── canghai/    portable personal-data adapters
└── openclaw/   plugin hooks and runtime adapters
```

Implementation has not started. Architecture contracts under `docs/` are the current source of truth.
