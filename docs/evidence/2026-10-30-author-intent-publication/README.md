# Single author-intent publication core — offline candidate

Base: `3ee2e70df8ca3e045f891a12c1c7ee53c7700d0a` (2026-10-30). Pending independent review; no plugin/Host/production wiring. Contract: [author-intent draft](../../design/2026-10-30-core-realignment/author-intent-contract-draft.md). Results and exact source/log hashes: [verification-summary.json](verification-summary.json).

Two new modules and one focused test file implement a single logical asset. The repository reuses `applyMemoryTransaction`, canonical journal parsing, `canonicalJson`/`bytesVersion`, and exact committed Git blob reading. It does not call the old correction coordinator, native lease, SQL bridge, external checkpoint authority, or remote durability class. It makes no USER/MEMORY writes and invokes no LLM.

The current document, its exact history copy, operation result and journal are published in one bounded local Git commit. The file transaction fence stays on disk when replacement or commit acknowledgement fails; controlled reads reject until exact-intent recovery. Individual renames are not a simultaneous multi-file transaction. Local success does not mean remote synchronization. The writer/fence is cooperative and repository-local; source adapters must provide stable, independently verified source versions within that coordination boundary. No cross-service source transaction, hostile-filesystem defense or instantaneous policy revocation is claimed. Git history is the local publication reference; there is no claim that an arbitrary copied repository is the latest backup.

Qualification is injected through required, trusted caller-owned ports. `assertRequest` must bind the actual request, admitted permissions and lifetime; `assertSources` must validate source bindings and permission to use/retain the exact excerpts. `currentSourceVersion` supplies an independently observed version. `verifyAuthor` must independently attest source ID/version/author/location/excerpt hash, rather than echo model input. These ports are not implemented by a Host adapter here, and the fixtures do not prove a real author-confirmation path. No tool is registered in this package. A future adapter must keep trusted ports out of model arguments; an owner boolean or model-supplied source metadata is not an author attestation.

A publication marked `candidate` cannot populate original-intent/established/current-interpretation fields or erase a previously confirmed asset. Confirmed publication requires an attested author trigger and author-backed authoritative statements. This is structural validation, not a judgment that natural language explicitly confirms the model's interpretation. That judgment remains a semantic-stage responsibility. Known USER/MEMORY conflicts are carried in the asset, without writing those authorities; semantic conflict resolution is not certified by this parser.

Expected asset/source conflicts refuse publication without writes. The frozen proposal identity includes its original expectation. Same operation and proposal resumes its original journal; changed input under the same ID refuses. An old successful operation returns its original published version and the separately observed current version, without reverting a later publication. Current reads reject changed source versions; authorized historical reads remain explicitly historical. Each read/replay obtains qualification anew; no authorization or process-local success cache is persisted.

Final verification: **20 new tests + 18 existing transaction/journal tests = 38 pass, 0 fail/cancel/skip**, plus test compilation, typecheck and build exit 0. Replacement obstruction, precommit/source changes, committed-but-unacknowledged and lost-response boundaries are covered. A separate Node process recovered the same committed operation without a second commit. The 20 new author-intent cases use synthetic repositories without remotes and never push their assets. Scope deviation: one of the existing primitive regression cases performs Git sync to its own temporary local bare repository. It used no external remote/network and its fixture cleanup completed, but it exceeded the strict no-push test boundary; it is disclosed and was not rerun. Initial and subsequently discovered red cases retain their original raw-log hashes; raw logs are not copied into the public project.

Existing CI at this base is separately reported by the coordinator as 1706 tests / 1672 pass / 34 fail; this package neither diagnoses nor fixes it. Historical 26-failure/152-probe evidence and the paused legacy candidate are not rewritten. The 27 pre-existing dirty files remained byte-identical. Real Host/harness integration, real author evidence, actual model/semantic outcomes, full consumer/formal gates, remote sync and cross-system publication remain unverified.
